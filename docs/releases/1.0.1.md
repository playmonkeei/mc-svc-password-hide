## Hide group passwords while you play, record, or stream

SVC Password Hide masks Simple Voice Chat group passwords by default and adds an
eye button to reveal or hide them. Version 1.0.1 includes a dark, high-contrast
button with a visible hover and keyboard-focus border.

- Covers both creating a group and joining a password-protected group.
- Resets to hidden when reopening the dialog or resizing the window.
- Preserves normal password entry, pasting, selection and group joining.
- Keeps hidden passwords out of Minecraft's narration.
- Includes English and German labels and tooltips.
- Client only: servers and other players do not need this add-on.

## Downloads

Choose one JAR for your Minecraft version and loader, or download the complete
`svc-password-hide-1.0.1.zip` and extract the matching file.

| Loader | File ending |
| --- | --- |
| Fabric or Quilt | `-fabric-quilt.jar` |
| Forge | `-forge.jar` |
| NeoForge | `-neoforge.jar` |

Available for Minecraft **26.1, 26.1.1, 26.1.2, 26.2 and 26.3**.

Requires **Java 25** and **Simple Voice Chat 2.6.x** for the same Minecraft version
and loader. Put the selected JAR in your client's `mods` folder and replace any
older copy of SVC Password Hide.

The release workflow builds and tests all five Minecraft targets before publishing.
Automated checks use Simple Voice Chat 2.6.24; full gameplay testing has not been
performed for every loader/version combination. `SHA256SUMS` is included for
download verification.
